About us

Small studio, full-stack craft.

SolbaTechs is an independent software company. We build our own products and help others build theirs — combining game development, app engineering and data science under one roof.

Every product we ship runs on both the web and mobile, sharing one codebase philosophy: fast, accessible and built to last.

  • Cross-platformOne product, every screen — browser, iOS and Android.
  • Data-drivenAnalytics and ML built in, not bolted on.
  • Player & user firstDesign decisions start with the people using it.
  • Ship & iterateRelease early, measure, improve continuously.
